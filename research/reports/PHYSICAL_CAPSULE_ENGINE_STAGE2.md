# Physical Capsule Engine — этап 2: эталонная модель на Python

Дата: 2026-11-22 · Код: `research/capsule_engine/` · Запуск проверок: `.venv/Scripts/python.exe -m research.capsule_engine.tests`

## 1. Что сделано

| Модуль | Содержание |
|---|---|
| `capsule.py` | Капсюль с постоянным зарядом: V = Q / (C(x) + Cp), ёмкость интегрируется по радиусу, форма прогиба «поршень» или «параболическая». Параметры безразмерные: смещение/зазор при 94 дБ SPL и Cp/C0. Оба неизвестны для C-800G, поэтому задаются диапазоном |
| `triode.py` | Каскад с общим катодом в топологии платы MA-55, номиналы со схемы (VERIFIED). Модель лампы Корена. Конденсаторы C104 и C102 дискретизированы трапецией, одно нелинейное неизвестное (ток анода) на сэмпл. Ньютон в вилке, не более 40 итераций — ограниченное худшее время |
| `oversample.py` | Передискретизация (полифазный FIR) вокруг нелинейных блоков |
| `analysis.py` | Гармоники, THD, энергия алиасинга |
| `tests.py` | 21 проверка по `VALIDATION_PLAN_RU.md` §1–3 |

## 2. Результаты проверок (21/21)

- **Капсюль, аналитика.**
  - Поршень без Cp: THD 4·10⁻¹⁵, то есть строго линеен, как и должно быть при постоянном заряде.
  - Поршень с Cp = C0: H2/H1 совпадает с формулой (1 − c)·a/2 до 4 знаков.
  - Параболический прогиб: H2/H1 = 8,329·10⁻⁴ при формуле a/12 = 8,333·10⁻⁴ (погрешность квадратуры 0,06 %).
- **Каскад, малый сигнал против аналогового прототипа** на 5 Гц, 50 Гц и 1 кГц при 44,1, 48, 96 и 192 кГц: расхождение ≤ 0,0001 дБ и ≤ 0,001°. Дискретизация корректна, поведение от частоты дискретизации не зависит.
- **Рабочая точка:** невязка законов Кирхгофа 2·10⁻¹⁹ А.
- **Устойчивость:** импульсная характеристика затухает; при входе 500 В выход конечен и ограничен питанием.
- **Уровни с шагом 6 дБ:** THD растёт монотонно.
- **Алиасинг при 4,567 кГц и сильной перегрузке:** без передискретизации −54 дБ, при 2×/4×/8× −79 дБ. Это пол измерения: окно и фильтры ресэмплера.

**Важно.** Все проверки каскада выполнены на **TEST-ONLY** константах Корена для 12AX7 — это другая лампа, опубликованная модель. Они проверяют только математику решателя. С ними рабочая точка получается 0,74 мА / 156 В, а не 1,4 мА / 90 В, как на схеме C-800G. Это ожидаемо.

## 3. Чего не хватает для модели именно C-800G

1. **Константы 6AU6A в триодном включении.** Их нужно подобрать по анодным характеристикам из даташита производителя лампы. Нужна загрузка PDF даташита — по согласованию.
   - **Независимая проверка без подгонки:** с подобранными константами модель обязана сама попасть в рабочую точку со схемы (Ia ≈ 1,4 мА, Ua ≈ 90 В, Uk ≈ 1,4 В). Схема в подборе не участвует.
2. **Сеточный ток.** Без него нельзя честно проверить 1 % THD при 131 дБ SPL: по оценке этапа 1 сетка там уходит в положительную область. Модель сеточного тока появится на этапе 3; его параметры тоже берутся из даташита.
3. **Нагрузка первичной обмотки R_L.** Зависит от трансформатора и входа предусилителя, она неизвестна. Будет изучена как диапазон: например, 1 кОм × 7² ≈ 49 кОм и выше.
4. **Ёмкость капсюля, Cp и прогиб мембраны** остаются неизвестными. Их влияние будет показано диапазоном в отчёте о неопределённости (этап 4).

## 3а. Лампа 6AU6A: подбор по даташиту GE (выполнено 2026-11-22)

**Источник.** Даташит GE ET-T916A (4-60), `docs/manufacturer_data/tube_6au6a/6au6a_general_electric.pdf`. Скачан с frank.pocnet.net с разрешения заказчика, SHA-256 `c88762ab…ad66`. На стр. 4 — анодные характеристики в триодном включении для Ec1 = 0…−12 В.

**Оцифровка.** 111 точек: пересечения кривых на 11 уровнях тока от 0,75 до 27,75 мА. Скрипт: `tools/manufacturer/digitize_triode_curves.py`, данные: `research/capsule_engine/fit_6au6a.py`. Наложение трассы и модели на график проверено визуально; картинка в git не кладётся, это производная от даташита.

**Константы Корена** (INFERRED, подбор по относительной ошибке тока): μ = 37,69; ex = 1,272; kG1 = 276,9; kP = 249,8; kVB = 222,6. Файл: `data/manufacturer/tube_6au6a_triode.json`.

**Ошибка подбора.** СКО по анодному напряжению 3,9 В, по току 8,4 %. Худшие точки — кривая Ec1 = 0 выше 20 мА (до +17 В): у модели Корена там не хватает гибкости. В рабочей области C-800G (1–3 мА, Ugk −1…−2 В) трасса проходит по кривым.

**Независимая проверка по таблице «типовой режим» GE, стр. 2** (в подборе не участвовала):

| | Опубликовано | Модель |
|---|---|---|
| Ib при 250 В, Rk = 330 Ом | 12,2 мА | 12,15 мА |
| μ | 36 | 36,2 |
| gm | 4800 мкСм | 5515 мкСм (+15 %) |

**Проверка по схеме C-800G, без подгонки.**
- **Сетка 0 В по постоянному току:** модель даёт Ia = 1,54 мА, Ua = 75,7 В, Uk = 1,54 В. На схеме ≈ 1,4 мА, 90 В, 1,4 В. Ток отличается на +10 %, анод на −14 В.
- **Возможные причины (INFERRED):**
  1. Накал 5,7 В вместо 6,3 В: эмиссия ниже, а кривые GE сняты при номинальном накале.
  2. Охлаждение лампы элементом Пельтье.
  3. Контактная разность потенциалов: при утечке сетки 500 МОм она смещает сетку в минус. Рабочую точку схемы точно даёт смещение сетки −0,61 В — величина типичного порядка для такого эффекта, но не измерена.
  4. Разброс ламп: у GE «средние» кривые.
  5. На схеме значения указаны как «about».
- В модель ни одна из этих поправок не внесена.

**Оценка искажений** (рабочая точка модели, сетка 0 В). Чувствительность −32 дБВ/Па (паспорт); коэффициент передачи от сетки до выхода по модели 11,4–12,2 дБ при R_L от 49 до 100 кОм.

| SPL | THD (R_L = 49 кОм) | THD (R_L = 100 кОм) |
|---|---|---|
| 94 дБ | 0,04 % | 0,03 % |
| 114 дБ | 0,38 % | 0,26 % |
| 124 дБ | 1,19 % | 0,82 % |
| 131 дБ | 2,67 % | 1,82 % |

- **Паспорт: 1 % THD при 131 дБ SPL. Модель доходит до 1 % на ~5–8 дБ раньше.** Это расхождение, и подгонкой его не убирали.
- **Кандидаты:**
  1. рабочая точка (см. выше);
  2. точность модели Корена при малых токах;
  3. неизвестная нагрузка R_L;
  4. методика паспорта (у Sony условие измерения не описано);
  5. трактовка 17 дБ усиления из JAS: модель даёт от сетки до анода 28–30 дБ, а 17 дБ ни одной очевидной точке цепи не соответствуют.
- Разбор — на этапе 3.

## 4. Производительность
Эталон написан на чистом Python и не оптимизирован: 21 проверка выполняется ~2,5 мин. Для реального времени будет C++ (этап 5); там решатель тот же, но без накладных расходов интерпретатора.
