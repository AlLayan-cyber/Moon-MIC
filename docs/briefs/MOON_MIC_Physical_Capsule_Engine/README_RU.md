# MOON MIC — Physical Capsule Engine
## Пакет задания для Claude

Этот архив содержит техническое задание и архитектурную основу для исследования и прототипирования физической модели микрофонного капсюля, начиная с Sony C-800G.

**Главная цель:** исследовать возможность моделировать не только частотную окраску микрофона, но и физически обоснованную цепочку преобразования звукового давления в электрический сигнал: акустическая нагрузка → движение мембраны → изменение ёмкости → электрический отклик → электроника микрофона.

Это исследовательская спецификация, а не утверждение, что все параметры Sony C-800G уже известны. Неизвестные параметры должны оставаться неизвестными до появления достоверного источника или измерений.

## Файлы
- `TASK_FOR_CLAUDE_RU.md` — основное задание Claude.
- `TECHNICAL_ARCHITECTURE_RU.md` — предлагаемая архитектура и математическая модель.
- `RESEARCH_AND_EVIDENCE_RU.md` — известные сведения, ограничения и правила работы с источниками.
- `PARAMETERS_TEMPLATE.csv` — шаблон реестра параметров капсюля.
- `VALIDATION_PLAN_RU.md` — план проверки модели.

## Важные правила
1. Не выдавать гипотезы за спецификации Sony.
2. Не подменять физическую модель обычным EQ.
3. Не заявлять, что плагин воспроизводит взаимодействие с воздухом «точно как оригинал», пока это не подтверждено измерениями.
4. Не начинать с тяжёлой CFD/FEM-модели в реальном времени. Исследовать редуцированные модели, пригодные для аудио DSP.
5. Разделять физическую модель капсюля, модель электроники и финальную калибровочную коррекцию.
6. Все параметры должны иметь источник, статус достоверности, единицы измерения и диапазон неопределённости.
