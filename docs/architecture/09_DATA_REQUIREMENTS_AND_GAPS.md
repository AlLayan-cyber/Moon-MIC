# 09 — Требования к данным и пробелы

Дата: 2026-11-21 · Статус: на основе аудита `docs/research/RESEARCH_STATUS.md`

Обозначения: **M** — есть измерение (Surrey), **M*** — есть, но с оговорками, **P** — только физическая модель, **—** — нет данных, **Own** — требуется собственное измерение.

## 2. 6 микрофонов без данных (U67, C12, SM7B, AT5040, NT1 5th Gen, ELA M 251E)
Все параметры — **Own**. По правилу D-005 модели не выпускаются до получения данных.

## 3. Отдельные проблемы данных
- C800 vs C-800G — вариант не подтверждён.
- U47 FET 5 м 24-bit: файлы в папке 32bit.
- Нормализация Surrey проверена только на одном наборе.
- Неизвестна модель предусилителя в измерениях Surrey.

## 4. Документы, которые нужно получить
- Даташиты и руководства всех 11 микрофонов (АЧХ, полярные диаграммы, чувствительность, шум, макс. SPL, переключатели, выходной импеданс).
- Схемы электроники микрофонов (для L3 и порядка L2/L3).
- Подтверждение от авторов Surrey: модель предусилителя, вариант Sony.

## 5. Приоритет закрытия пробелов
1. Ближнее поле и proximity (5–30 см) для 5 микрофонов из Surrey — проверка модели 03.
2. Нелинейность при высоких SPL и калибровка чувствительности.
3. Полные измерения 6 недостающих микрофонов.
4. Вертикальная плоскость.
5. Разброс экземпляров (хотя бы 2 экземпляра для 1–2 моделей, чтобы оценить масштаб).
