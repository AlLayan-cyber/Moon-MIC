# 02 — Microphone Modeling Engine

Дата: 2026-11-21 · Статус: проект · Используется в SIGNATURE и TRANSFORM

## 1. Слои модели

| Слой | Содержание | Природа | Источник данных |
|---|---|---|---|
| L1 Пространственное ядро | H(f, θ, φ, r): амплитуда и фаза, направленность, off-axis, дистанция, proximity | Линейный, зависит от позиции | Surrey (5 мик.) + собственные измерения + физическое продолжение (03) |
| L2 Переключатели микрофона | Направленность (у многорежимных), pad, HPF, тональные переключатели — по даташиту каждой модели | Линейный | Даташиты — **UNKNOWN**, на диске их нет |
| L3 Нелинейность | Капсюль при высоком SPL, импедансный преобразователь (лампа / FET / трансформатор), для динамических — магнитная система | Нелинейный, зависит от уровня SPL | Только собственные измерения (12). В Surrey недостаточно: 83 dB(A), 16 бит |
| L4 Собственный шум | Спектр шума конкретного экземпляра | Аддитивный | Собственные измерения |
| L5 Метаданные | Экземпляр (серийный номер), дата, состояние, источник каждого параметра | — | Манифест |

Порядок обработки внутри модели (INFERRED, подтверждается проверкой): L1 → L2 (часть переключателей стоит до электроники, часть после) → L3 → L4. Точный порядок L2/L3 определяется по схеме конкретного микрофона.

## 2. Представление пространственного ядра
Варианты (выбор после проверки на данных):
1. **Таблица FIR по углам** (72 угла × дистанции) с интерполяцией. Самый «сырой» и точный в измеренных точках вариант, но дистанции между точками не продолжает.
2. **Разложение по направленности:** для микрофонов первого порядка H(f, θ) ≈ A(f) + B(f)·cos θ (давленческая + градиентная составляющие) плюс остаток высших порядков R(f, θ). Позволяет физически продолжать на любую дистанцию (03) и сжимает данные.
3. **Сферические гармоники**, когда появятся вертикальные измерения.

**Рекомендация (INFERRED):** вариант 2 как основа, остаток R(f, θ) хранить явно. Вариант 1 использовать как эталон при проверке.

Для каждого слоя хранится комплексная характеристика (амплитуда и фаза). Только амплитудная модель запрещена (см. 04).

## 3. Многорежимные микрофоны
- U87 Ai, C414 B-XLS, K2: измерены отдельно O, C, B (у C414 ещё Hyper). Модель хранит каждый режим.
- Промежуточные положения переключателя (у K2 и C414 непрерывные / многопозиционные — **UNKNOWN** до даташита) моделируются как комбинация двух мембран. Обоснованность нужно проверить: собрать C из O и B и сравнить с измеренной C.
- Sony C-800G: в Surrey «C800» C и O; вариант G — **UNKNOWN**.

## 5. Важные правила
- Модель привязана к **конкретному измеренному экземпляру**, а не к «модели вообще». Особенно для винтажных U67, C12 и ELA M 251E с большим разбросом.
- В модель не входит измерительная цепочка (колонка, предусилитель, интерфейс). Её надо вычесть (04).
- Нелинейность L3 зависит от **реального SPL**. Поэтому уровень обязательно калибруется dBFS → SPL. Без калибровки нелинейность включается произвольно, а это главный источник «игрушечного» звука.
- Все нелинейные блоки работают с оверсэмплингом и контролем алиасинга (11).

## 6. Открытые вопросы
1. Порядок L2/L3 и топология электроники для каждой модели (нужны схемы).
2. Нужна ли динамическая (зависящая от уровня) часть L1 — например, нелинейность мембраны капсюля при очень высоком SPL. Проверяется измерениями.
3. Достаточно ли модели первого порядка для двухмембранных капсюлей на ВЧ (ожидаемо нет, поэтому остаток R хранится явно).
