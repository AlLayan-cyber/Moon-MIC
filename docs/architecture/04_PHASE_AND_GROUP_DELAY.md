# 04 — Фаза и групповая задержка

Дата: 2026-11-21 · Статус: проект

## 1. Почему фаза обязательна
Амплитудная модель без фазы даёт неверную форму атак и неверное поведение при смешивании с другими микрофонами. Она также не передаёт характер proximity на НЧ (03). Поэтому модель хранит комплексную характеристику.

## 2. Что измеримо, а что только моделируется

| Параметр | Surrey | Свои измерения | Только модель |
|---|---|---|---|
| Фаза на оси, выше ~60 Гц | Да, вместе с цепочкой | Да | — |
| Фаза по углам (шаг 5°) | Да, горизонталь | Да + вертикаль | — |
| Групповая задержка | Вычисляется из IR | Да | НЧ ниже предела окна |
| Абсолютная задержка / акустический центр | Потеряна (окно центрировано) | Да, при синхронной эталонной записи | Частично |
| Фаза в ближнем поле < 0,5 м | Нет | Да | Продолжение по 03 |
| Абсолютная полярность | **UNKNOWN** (не проверялась) | Да | — |

## 3. Компенсация измерительной цепочки
Surrey IR = микрофон × колонка Genelec 8040 × неизвестный предусилитель × RME (× окно). Цепочка не вычтена (см. `docs/research/SURREY_DATASET_METHODology.md`).

Предлагаемый метод (INFERRED, проверяется):
1. Измерение эталонного NTi M2211 в том же наборе используется как оценка «колонка + помещение-в-окне + цепочка».
2. H_mic ≈ H_measured / H_M2211 с регуляризацией вне полосы, где M2211 надёжен.
3. Остаётся собственная характеристика M2211. Она Class-1, но не идеальна, и её калибровочные данные **UNKNOWN**.
4. Предусилитель мог меняться между сессиями, а усиление менялось для каждого микрофона. Если характеристика предусилителя зависит от усиления, компенсация будет неточной (UNKNOWN).

## 4. Проверки выравнивания (до использования данных)
- Одинаково ли центрирование окна для всех 72 углов одной серии? Спот-проверка: пик на отсчёте 705–706, но это не доказательство.
- Совпадает ли акустический центр капсюля с осью вращения? Если нет, по углам появится систематическая задержка, зависящая от угла. Её надо отделить от свойства микрофона.

## 5. Представление в DSP
- Разделение: H = H_minphase × H_allpass(excess) × задержка.
- **Режим низкой задержки:** минимально-фазовая часть + аппроксимация excess phase IIR-allpass там, где она значима (НЧ proximity, область резонанса мембраны).
- **Режим высокой точности:** полная измеренная фаза, FIR, задержка сообщается хосту.
- Разница между режимами проверяется измеримо (10), а не «на слух».

## 6. Групповая задержка как метрика качества
Ошибка групповой задержки модели относительно эталона — одна из метрик приёмки (10). Допуски задаются после пилотных измерений.
