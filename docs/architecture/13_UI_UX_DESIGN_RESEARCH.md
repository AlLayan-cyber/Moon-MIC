# 13 — Исследование интерфейса (UI/UX)

Дата: 2026-11-21 · Статус: исследование, дизайн не начат · Решение D-008: интерфейс уровня ведущих производителей

> Обзор конкурентов составлен по знаниям на момент написания, **без свежей проверки актуальных версий** (INFERRED). Перед началом дизайна нужно пройтись по текущим версиям продуктов.

## 1. Цель
Интерфейс должен выглядеть и работать как продукт ведущих компаний, без «игрушечности». Он должен делать физику модели наглядной и не обманывать пользователя: честное A/B, видимое происхождение данных.

## 2. Прямые конкуренты в моделировании микрофонов (INFERRED)

| Продукт | Подход | Интерфейс | Чего не хватает |
|---|---|---|---|
| Universal Audio / Townsend Labs Sphere | Специальный двухканальный микрофон + плагин | Выбор модели, управление полярной диаграммой, off-axis, proximity регуляторами | Нет наглядной сцены, нет данных о происхождении модели |
| Slate Digital VMS | Свой микрофон + плагин | Простой выбор модели | Минимум визуализации и пространственных параметров |
| Antelope Edge | Свой микрофон + DSP в интерфейсе | Выбор модели, параметры направленности | Привязка к своему «железу» |

**Окно возможностей:** никто из них не показывает реальную физику (позиция певца, диаграмма направленности на частоте, proximity в реальном времени) и источник данных модели.

## 3. Эталоны качества интерфейса (INFERRED)

| Компания / продукт | Чему учиться |
|---|---|
| FabFilter (Pro-Q, Pro-C) | Векторный масштабируемый UI, живой анализатор, прямое редактирование на графике, продуманные мелочи (подсказки, жесты, клавиатура) |
| iZotope (Nectar, Ozone) | Анализ с подсказками, понятная визуализация того, что делает «умная» часть — близко к TRANSFORM |
| Universal Audio (UADx), Softube, Brainworx / Plugin Alliance | A/B-сравнение, подбор громкости, браузер пресетов с тегами |

**Общие стандарты отрасли (2024–2026, INFERRED):**
- векторная графика и масштабирование под HiDPI;
- тёмная тема со сдержанными акцентами;
- отмена и повтор действий (undo/redo);
- сравнение A/B с копированием состояния;
- всплывающие подсказки и режим справки;
- большие точные индикаторы уровня;
- **bypass с выравниванием громкости**;
- браузер пресетов с тегами и поиском;
- полная автоматизация параметров в DAW.

## 4. Концепция MOON MIC

### 4.1 Главные элементы
1. **Вид сверху на сцену («Stage View»).** Певец перетаскивается мышью: дистанция и угол относительно капсюля. Главный элемент интерфейса. В SIGNATURE позицию задаёт пользователь. В TRANSFORM показывается оценённая позиция источника (только отображение, с индикатором доверия) и целевая позиция.
2. **Живая полярная диаграмма** на выбранной частоте или полосе. Переключение частоты, наложение нескольких частот.
3. **Кривая proximity и АЧХ в реальном времени.** Меняется при движении певца и переключении направленности.
4. **Переключатель SIGNATURE / TRANSFORM** — крупный и однозначный.
5. **Панель TRANSFORM:**
   - выбор исходного микрофона (приоритетнее автоматической оценки, см. 05);
   - индикатор доверия AI-оценки;
   - сила коррекции.
6. **Метка происхождения данных:** измеренный экземпляр, дата, статус VERIFIED. Прозрачность как профессиональное преимущество.
7. **Калибровка уровня SPL** — видимая и понятная: от неё зависит честность нелинейности (02, 11).
8. **Переключатели микрофона** (направленность, pad, HPF) — только те, что есть у реального экземпляра.

### 4.2 Служебное
- Индикаторы входа и выхода, отображение оценённого SPL.
- Bypass с выравниванием громкости, A/B.
- Отображение задержки и выбор режима: низкая задержка / высокая точность (04).
- Выбор режима анализа: Real-time / Pre-analysis (06).
- Собственный шум микрофона: опция, по умолчанию выключена.

## 5. Визуальный стиль
- Чистый векторный современный стиль.
- **Без фотореалистичных изображений микрофонов и логотипов брендов.** Это современный уровень и одновременно снятие юридических рисков (11 §4). Решение с юристом обязательно до релиза.
- Данные показываются точно: графики строятся из реальной модели, а не рисуются «для красоты».

## 6. Запреты
- Никаких «магических» регуляторов без физического смысла («Warmth», «Magic», «AI Boost»).
- Никакой визуализации, которая не соответствует реальной обработке.
- Никаких ложных индикаторов (например, «AI работает» в SIGNATURE: там AI нет по D-001).

## 7. Открытые вопросы
1. Фреймворк UI и рендеринг (векторный, GPU): выбор на этапе реализации, после команды «НАЧИНАЕМ СБОРКУ».
2. Нужна ли вертикальная плоскость в Stage View в v1 — зависит от наличия вертикальных измерений (09).
3. Свежий обзор текущих версий конкурентов перед дизайном.
4. Привлечение UI/UX-дизайнера с опытом в аудиоплагинах.
