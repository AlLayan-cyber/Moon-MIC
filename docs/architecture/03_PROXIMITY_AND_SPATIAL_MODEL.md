# 03 — Proximity Effect и пространственная модель

Дата: 2026-11-21 · Статус: проект · **Обязательная часть SIGNATURE и TRANSFORM** (решение D-003)

## 1. Требование
Proximity effect моделируется **индивидуально** для каждого микрофона, каждой направленности, угла, дистанции и частоты. Одна кривая на все модели запрещена.

## 2. Физическая основа (теория, стандартная акустика)
- Давленческая (ненаправленная) часть капсюля почти не реагирует на кривизну волнового фронта.
- Градиентная часть реагирует на разность давлений. В сферической волне от точечного источника на расстоянии r она содержит дополнительный член, растущий к НЧ: множитель ≈ (1 + 1/(jkr)), где k = 2πf/c.
- Отсюда следует:
  - «Восьмёрка» (чистый градиент) даёт максимальный подъём, кардиоида и гиперкардиоида — частичный, чистая «круговая» — практически никакого.
  - Градиентная часть пропорциональна cos θ, поэтому подъём **зависит от угла**. У «восьмёрки» при 90° он пропадает вместе с сигналом, у кардиоиды меняется с углом иначе.
  - Член 1/(jkr) влияет и на **фазу** на НЧ, а не только на амплитуду.
- У реальных капсюлей, особенно двухмембранных (U87 Ai, C414, K2, C800), соотношение давленческой и градиентной частей **меняется с частотой**. Отсюда и индивидуальная кривая.

## 3. Модель (INFERRED, проверяется на данных)

```
H(f, θ, r) ≈ [ A(f) + B(f)·cos θ · G(f, r) + R(f, θ, r) ] · e^(−jkr)/r · (нормировка)
G(f, r) = 1 + 1/(j·k·r_eff)
```
- A(f), B(f) — давленческая и градиентная составляющие конкретного капсюля и режима.
- R — остаток высших порядков (дифракция на корпусе, неидеальность капсюля).
- r_eff — эффективное расстояние до акустического центра капсюля. Он не совпадает с центром вращения и может зависеть от частоты, поэтому оценивается при подгонке.

**Подгонка:** совместно по всем трём дистанциям Surrey. Даже 1,25 м — не дальнее поле на НЧ (при 60 Гц kr ≈ 1,4), поэтому подгонять только по «дальней» точке нельзя.

## 4. Проверка до реализации
1. **Предсказание дистанции:** подгонка по 1,25 и 5 м → предсказание 0,5 м → сравнение с измерением (амплитуда и фаза).
2. **Сборка режимов:** у U87 Ai, C414 и K2 собрать C из измеренных O и B → сравнить с измеренной C.
3. **Ближнее поле 5–30 см:** проверяется только собственными измерениями (12). В Surrey данных нет.

## 5. Ограничения
| Ограничение | Статус |
|---|---|
| Дистанции < 0,5 м не измерены | VERIFIED (Surrey). Нужны свои измерения |
| НЧ ниже ~60 / 68 / 125 Гц (0,5 / 1,25 / 5 м) неточны из-за окна | VERIFIED (Surrey p.7) |
| Рот — не точечный источник; на 5 см модель точечного источника приближённая | INFERRED |
| Только горизонтальная плоскость | VERIFIED (Surrey) |
| Динамические (SM7B) — тоже градиентные, но с механическими резонансами; данных нет | INFERRED / UNKNOWN |

## 6. Использование в режимах

**SIGNATURE:** пользователь задаёт дистанцию, угол (и позже вертикальный угол). Модель даёт измеренный и физически продолженный proximity выбранного микрофона и режима. Никакой автоматики.

**TRANSFORM:** итоговая коррекция
```
H_T = H_target(f, θ_t, r_t) / H_source(f, θ_s, r_s)
```
- (r_s, θ_s) оценивает Adaptive Control или задаёт пользователь. (r_t, θ_t) по умолчанию равны (r_s, θ_s): «тот же певец в том же месте, но другой микрофон».
- Убрать proximity исходника — значит ослабить НЧ, это безопасно. Добавить proximity цели там, где у исходника мало энергии, означает поднять шум. Поэтому усиление **регуляризуется и ограничивается**, а пределы фиксируются в 05.
- Позиция меняется во времени (певец двигается), поэтому параметры сглаживаются. Скорость изменения ограничена физически правдоподобными значениями.

## 7. Взаимодействие угол × дистанция × частота
Модель из §3 описывает его явно: угол влияет через cos θ и R, дистанция — через G и e^(−jkr)/r, частота — через A, B, R и k. Отдельных «кривых proximity», не связанных с моделью направленности, не существует.
