# 07 — Вычислительное физическое моделирование

Дата: 2026-11-21 · Статус: исследование · Роль: **заполнение пробелов**, а не основа (решение D-006)

## 1. Где физика нужна
| Пробел | Физический инструмент |
|---|---|
| Ближнее поле < 0,5 м, proximity | Аналитическая модель давление/градиент (03) — дешёвая, основная |
| НЧ ниже предела окна Surrey | Модель капсюля с сосредоточенными параметрами + аналитическое продолжение |
| Вертикальная плоскость (до появления измерений) | BEM-модель корпуса и сетки — только как временная оценка |
| Интерполяция между измеренными дистанциями и углами | Разложение 02/03 |
| Понимание резонансов и влияния конструкции | Модели с сосредоточенными параметрами и FEM |

## 2. Методы
1. **Эквивалентные схемы с сосредоточенными параметрами** (акустика ↔ механика ↔ электрика): мембрана (масса, натяжение), воздушный зазор, перфорированный задний электрод (демпфирование), задние полости, для двухмембранных капсюлей Braunmühl–Weber — связь мембран. Электрическая часть: ёмкость капсюля, поляризация, нагрузка преобразователя. Быстро, хорошо подгоняется к измерениям.
2. **FEM с термовязкой акустикой** для узких зазоров и перфорации. Офлайн, дорого.
3. **BEM** для дифракции на корпусе, сетке и держателе. Офлайн.

## 3. Конвейер
```
Геометрия / параметры → офлайн-расчёт → H_model(f, θ, φ, r)
       ▲                                     │
       └──── калибровка по измерениям ◄──────┘ (обратная задача)
Результат → компактное DSP-представление (02/04) → real-time движок
```
В реальном времени физика **не считается**. Переносятся только результаты.

## 4. Риски
| Риск | Статус |
|---|---|
| Геометрия капсюлей (зазоры, перфорация, полости) не опубликована | UNKNOWN. Источники: патенты, литература, разборы экземпляров |
| Некалиброванная физика даёт правдоподобный, но неверный результат | INFERRED. Поэтому физика без проверки по измерениям в продукт не идёт |
| Стоимость FEM/BEM (время, лицензии, экспертиза) | INFERRED. Использовать точечно |

## 5. Рекомендация
Этап 1: только аналитическая модель proximity (03) и подгонка моделей с сосредоточенными параметрами к измерениям Surrey и своим. FEM/BEM — только если после этого останутся пробелы, которые измерениями закрыть нельзя.
