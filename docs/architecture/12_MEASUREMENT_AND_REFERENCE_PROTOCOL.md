# 12 — Протокол собственных измерений и эталонных записей

Дата: 2026-11-21 · Статус: проект протокола. Конкретные параметры уточняются после пилота.

## 1. Цель
Закрыть пробелы (09): ближнее поле и proximity, нелинейность при вокальных SPL, вертикальная плоскость, чувствительность, шум, импеданс, 6 недостающих микрофонов, эталонные пары.

## 2. Совместимость с Surrey
Для сопоставимости используется тот же метод: синхронизированный экспоненциальный свип (Novak), деконволюция с разделением гармоник, шаг 5°, имена файлов в стиле Surrey. Отличия, которые делаем лучше: 24-битная (или выше) запись, известная и измеренная цепочка, ближнее поле, несколько уровней SPL.

## 3. Помещение
| Вариант | Плюсы | Минусы |
|---|---|---|
| Аренда безэховой камеры | Точные НЧ, вертикаль, без окна | Стоимость, доступность |
| Квазибезэховый метод в большом помещении (как Surrey) | Доступно | Предел по НЧ из-за окна |

Рекомендация (INFERRED): безэховая камера для ближнего поля, НЧ и вертикали хотя бы для пилота.

## 4. Оборудование (классы, не модели)
- Эталонный измерительный микрофон с индивидуальной калибровкой (Class 1).
- Калибратор SPL.
- Источник: компактный студийный монитор для дальнего поля + **малый источник** (имитатор рта / малый широкополосный излучатель) для ближнего поля 2–30 см.
- Предусилитель с измеренной плоской характеристикой и известным входным импедансом. Его характеристика вычитается.
- Аудиоинтерфейс 24/32 бит, 96 кГц.
- Поворотный стол с точностью не хуже Surrey (±0,1°) и возможностью наклона для вертикали.

## 5. Сетка измерений (предложение, уточняется)
- **Дистанции:** 2,5 / 5 / 10 / 15 / 20 / 30 / 50 / 125 см (перекрытие с Surrey на 50 и 125 см для сверки).
- **Углы:** горизонталь 0–355° шагом 5°. Вертикаль — тот же шаг в нескольких плоскостях.
- **Уровни SPL** для нелинейности: шаги до максимума, который выдерживают микрофон и источник. Целевой диапазон — вокальные уровни на малых дистанциях (точные значения после пилота).
- **Режимы и переключатели:** все положения направленности, pad, HPF.
- Дополнительно: собственный шум (в тихой камере), чувствительность (калибратор), выходной импеданс от частоты.

## 6. Эталонные пары записей
- Один и тот же вокал записывается **одновременно** целевым микрофоном и эталонным в одной позиции (капсюли максимально близко, позиции задокументированы).
- Несколько певцов (разные голоса, мужские и женские), разные стили, дистанции 5–30 см, углы 0/30/60°.
- Записи с движением певца — для проверки отслеживания позиции в TRANSFORM.
- Для TRANSFORM: та же сцена, одновременно на несколько разных микрофонов (источник ↔ цель).

## 7. Метаданные каждого измерения
Экземпляр (серийный номер), дата, температура и влажность, положение капсюля относительно оси вращения, цепочка (все устройства и настройки), калибровочный уровень, версии ПО. Запись в манифест `data/manifests/`.

## 8. Хранение
- Сырые записи → `data/raw/<источник>/…` (не изменяются).
- Обработанные → `data/processed/…`.
- Калибровки цепочки → `data/calibration/measurement_chain/`, `data/calibration/reference_mics/`.
