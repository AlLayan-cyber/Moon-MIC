# 08 — Интеграция предусилителей (этап 2)

Дата: 2026-11-21 · Статус: **отложено до завершения микрофонного ядра** (решение D-004)

## 1. Объём
Neve 1073, Tube-Tech MP1A. Анализ источников — в `docs/research/` (PREAMP_RESEARCH, NEVE_1073_ANALYSIS, TUBE_TECH_MP1A_ANALYSIS).

## 2. Место в цепочке
```
Microphone Modeling Engine → [интерфейс микрофон↔предусилитель] → Preamp Model → выход
```

## 3. Взаимодействие микрофона и предусилителя (важно для достоверности)
Звук реальной связки — это не просто «микрофон × предусилитель». Выходной импеданс микрофона (особенно с трансформатором, у ламповых и у динамического SM7B) нагружается входным импедансом предусилителя. Это меняет АЧХ и поведение на НЧ и ВЧ (INFERRED, стандартная электротехника). У 1073 входной импеданс переключается Hi/Lo (VERIFIED: S1 на EH10023), но его значения UNKNOWN. У MP1A входной импеданс тоже UNKNOWN.

Следствие: в архитектуре нужен блок взаимодействия импедансов. Для этого требуются:
- выходной импеданс каждого микрофона в зависимости от частоты (измерить);
- входной импеданс предусилителей в зависимости от частоты и положения переключателей (измерить).

## 4. Условия начала этапа 2
1. Микрофонное ядро прошло приёмку (10).
2. Есть измерения реальных блоков: частотная и фазовая характеристика по усилениям, THD/IMD в зависимости от уровня и частоты, клиппинг, EIN, импедансы.
3. Есть данные трансформаторов и питания или их измерения.
4. Для MP1A — официальная схема или подтверждение ревизии схемы Gyraf.

## 5. Запрет
Модели предусилителей не строятся только по схемам. Схема — основа топологии, но характер звука подтверждается измерениями.
