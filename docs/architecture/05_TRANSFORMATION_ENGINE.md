# 05 — Transformation Engine (режим TRANSFORM)

Дата: 2026-11-21 · Статус: проект

## 1. Задача
Преобразовать запись с исходного микрофона так, чтобы она звучала как запись целевым микрофоном **в той же позиции**. Артикуляция, тембр голоса и динамика исполнения сохраняются. Новых деталей не появляется.

## 2. Цепочка
```
x_source
 → калибровка уровня (dBFS → SPL)
 → [если известна] инверсия нелинейности исходного микрофона — по умолчанию НЕ выполняется (см. §5)
 → регуляризованная инверсия линейной модели источника H_source(f, θ_s, r_s)
 → целевая линейная модель H_target(f, θ_t, r_t)            ┐ объединяются в один
 → целевая нелинейность L3 при оценённом SPL                 ┘ фильтр, где возможно
 → x_out
```

## 3. Исходный микрофон
| Ситуация | Поведение | Сила коррекции |
|---|---|---|
| Пользователь выбрал исходник из библиотеки MOON MIC | Полная модель источника | Полная |
| Исходник оценён AI с высоким доверием | Модель источника + индикатор доверия в UI | Масштабируется по доверию |
| Исходник неизвестен | Обобщённая «нейтральная» модель | Ограниченная, с предупреждением |

Слепая оценка исходника плохо обусловлена: тембр голоса и тембр микрофона смешаны в одном спектре (INFERRED). Поэтому выбор пользователя приоритетнее автоматической оценки.

## 4. Регуляризация (защита от «игрушечного» звука и артефактов)
- Коррекция ограничена по усилению в каждой полосе (пределы задаются после пилота, а не придумываются).
- Там, где у исходника мало энергии (ниже его НЧ-среза, выше ВЧ-спада), не «дорисовываем» сигнал. Подъём ограничен, чтобы не поднимать шум.
- Временные изменения параметров сглажены. Скорость изменения позиции ограничена физически правдоподобными значениями.
- **Запрещено:** синтез гармоник или спектра, которых нет на входе, кроме измеренной нелинейности целевого микрофона; изменение огибающих атак сверх того, что даёт модель; спектральные «улучшатели».

## 5. Нелинейность
- Целевая нелинейность применяется при реальном (откалиброванном) SPL.
- Инверсия нелинейности исходника в общем случае некорректна (неоднозначна). По умолчанию она не выполняется. Достаточно того, что у большинства студийных микрофонов при нормальных уровнях нелинейность мала (INFERRED). Это проверяется измерениями.

## 6. Роль анализа вокала
Анализ (06) **не обрабатывает звук напрямую**. Он:
- выбирает надёжные участки для оценки параметров (например, дистанцию лучше оценивать на гласных с выраженной НЧ-энергией, ВЧ-характер исходника — на сибилянтах);
- даёт оценки r_s, θ_s, уровня и типа исходника с доверием;
- управляет сглаживанием (не менять параметры посреди атаки).

## 7. Проверка
- Эталонные пары (12): TRANSFORM(запись исходника) ↔ реальная запись целевым микрофоном.
- Null-тест: при источнике = цели и одинаковой позиции выход должен совпадать со входом в пределах допуска.
- Метрики и ABX — в 10.
