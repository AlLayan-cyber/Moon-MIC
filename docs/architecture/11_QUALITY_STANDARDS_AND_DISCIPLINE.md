# 11 — Стандарты качества и дисциплина разработки

Дата: 2026-11-21 · Статус: обязательные правила проекта

## 1. Правила работы с данными и моделями
1. **Прослеживаемость.** У каждого параметра модели есть ссылка на источник (файл, страница, измерение) и тег VERIFIED / INFERRED / UNKNOWN.
2. **Воспроизводимость.** Модель собирается из сырых данных конвейером с фиксированными версиями. Манифесты (хэши, версии, параметры) — в `data/manifests/`. Исходные данные не изменяются.
3. **Никакой ручной подкрутки EQ «на слух».** Любая коррекция модели документируется и обосновывается измерением.
4. **«Нет данных — нет модели»** (D-005).
5. **Явная маркировка экземпляра:** серийный номер, дата, состояние, условия измерения.
6. **Журнал решений:** каждое архитектурное решение записывается с датой и обоснованием (01 §6).
7. **SIGNATURE без AI** (D-001). Любой AI-компонент в SIGNATURE — нарушение архитектуры.

## 2. DSP-стандарты (против «игрушечного» звука)
| Требование | Суть |
|---|---|
| Оверсэмплинг нелинейных блоков | Алиасинг ниже порога, который определяется в 10 |
| Калибровка dBFS → SPL | Нелинейность зависит от реального давления, а не от громкости фейдера |
| Независимость от частоты дискретизации | Одинаковый результат на 44,1 / 48 / 88,2 / 96 / 176,4 / 192 кГц. Поведение выше 20 кГц, где данных нет, определено явно и документировано |
| Корректная задержка | Точно сообщается хосту. Есть режимы с низкой задержкой и с высокой точностью |
| Сглаживание автоматизации | Нет щелчков и «молнии» при изменении любых параметров |
| Детерминизм | Офлайн-рендер = real-time. Повторный рендер даёт идентичный результат |
| Стабильность | Нет денормалов, NaN/Inf, выделения памяти и блокировок в аудиопотоке |
| Bypass с компенсацией уровня | Честное A/B-сравнение без обмана громкостью |
| Фаза | Только комплексные модели. Только амплитудные запрещены |

## 3. Definition of Done для модели микрофона
1. Данные получены и задокументированы (09, 12).
2. Цепочка измерения вычтена и проверена (04).
3. Пространственная модель проверена на неиспользованных точках (03, 10).
4. Нелинейность проверена по уровням (10).
5. Эталонные пары пройдены, ABX выполнен (10).
6. DSP-стандарты §2 выполнены.
7. Манифест и метаданные экземпляра заполнены.
8. Юридическая проверка названия и изображений пройдена (§4).

## 4. Юридическое
Названия Neumann, AKG, Sony, RØDE, Shure, Audio-Technica, Telefunken и других — товарные знаки их владельцев. Использование названий, логотипов и изображений микрофонов в продукте и маркетинге решается **с юристом до релиза**. В документации проекта названия используются только как описание объекта исследования.
