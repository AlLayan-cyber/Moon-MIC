# MOON MIC — plugin

MOON AUDIO ENGINEERING · VST3 (Windows), AU (macOS builds only) · JUCE 9.0.4 · CMake

Current state: **SIGNATURE** (deterministic, no AI — decision D-001), **C-800G tube stage** (physical electronics model, Level control) and **TRANSFORM v1** (manual source mic and position, no AI analysis yet — `research/reports/TRANSFORM_V1_REPORT.md`).

## Build (Windows, Visual Studio 2026)
```
cmake -S plugin -B plugin/build -G "Visual Studio 18 2026" -A x64 -DJUCE_DIR=C:/JUCE
cmake --build plugin/build --config Release --target MoonMic_VST3 MoonMicTests MoonMicProcessorTests --parallel
```
The VST3 ends up in `plugin/build/MoonMic_artefacts/Release/VST3/MOON MIC.vst3`.
The build does not copy it into the system VST3 folder (`COPY_PLUGIN_AFTER_BUILD FALSE`).
To use it in a DAW, copy the `MOON MIC.vst3` folder to `C:\Program Files\Common Files\VST3\`.

## Build (macOS: VST3 + AU, universal arm64 + x86_64)
Requirements: Xcode (or Command Line Tools: `xcode-select --install`), CMake >= 3.22 (`brew install cmake`), git.
```
git clone --branch 9.0.4 --depth 1 https://github.com/juce-framework/JUCE.git ~/JUCE
cmake -S plugin -B plugin/build -G Xcode -DJUCE_DIR=$HOME/JUCE \
      -DCMAKE_OSX_ARCHITECTURES="arm64;x86_64" -DCMAKE_OSX_DEPLOYMENT_TARGET=11.0
cmake --build plugin/build --config Release --target MoonMic_VST3 MoonMic_AU MoonMicTests MoonMicProcessorTests --parallel
```
Results: `plugin/build/MoonMic_artefacts/Release/VST3/MOON MIC.vst3` and `.../Release/AU/MOON MIC.component`.
Tests: `plugin/build/MoonMicTests_artefacts/Release/MoonMicTests` and `.../MoonMicProcessorTests_artefacts/Release/MoonMicProcessorTests`.
Install for DAWs: copy to `~/Library/Audio/Plug-Ins/VST3/` and `~/Library/Audio/Plug-Ins/Components/`, then validate the AU with
`auval -v aufx MnMc MnAE`. Unsigned builds: macOS asks once (System Settings -> Privacy & Security -> allow).
JUCE_DIR defaults to `~/JUCE` on macOS and `C:/JUCE` on Windows.

## Tests
```
plugin/build/MoonMicTests_artefacts/Release/MoonMicTests.exe
plugin/build/MoonMicProcessorTests_artefacts/Release/MoonMicProcessorTests.exe
plugin/build/MoonMicProcessorTests_artefacts/Release/MoonMicProcessorTests.exe <png-prefix>   # UI snapshots
```
- `MoonMicTests` covers: model data loads, the FFT, the C++ target against the Python reference (114 cases), FIR accuracy, minimum phase and determinism.
- `MoonMicProcessorTests` runs the real audio path (processor, design thread, convolution) at 44.1, 48, 96 and 192 kHz,
  and the C-800G tube stage: linear at low level (vs target), THD vs the Python reference at 114 / 131 dB SPL,
  and Level having no effect on microphones without an electronics model.

## Model data
`resources/models/moonmic_signature_v1.bin` is generated by `tools/export/export_signature_models.py`
from the Phase 1 pipeline (`research/reports/PHASE1_SURREY_PIPELINE_REPORT.md`).
Provenance (source files and SHA-256): `resources/models/moonmic_signature_v1.json`.
After changing the exporter, re-run it. It also regenerates `tests/reference/signature_reference_v1.json`.

## Layout
```
source/model/ModelLibrary.*        MMIC v1 parser (embedded binary data)
source/dsp/SignatureDesigner.*     spatial model + minimum-phase FIR design (background thread)
source/dsp/SimpleFFT.*             deterministic radix-2 FFT for design
source/dsp/CapsuleEngine.h         physical electronics core (6AU6A triode stage, capsule), shared with
                                   research/capsule_engine_cpp (bench vs the Python reference)
source/dsp/ElectronicsStage.*      C-800G tube stage after the linear model: 2x IIR oversampling,
                                   Level = dB SPL at the capsule for a full-scale sine (default 120)
source/PluginProcessor.*           parameters, design thread, zero-latency convolution, gains
source/PluginEditor.*              editor: SIGNATURE/TRANSFORM, mic + pattern selectors, A/B, bypass
source/ui/StageView.*              top-down stage, draggable singer/source, model polar pattern
source/ui/PolarPlot.*              polar display, up to 4 frequencies (model, current distance)
source/ui/ResponsePlot.*, MoonAudioLogo.*, Theme.h
resources/branding/                logo source PNG + vector SVG
tests/                             test runners + Python reference vectors
```
